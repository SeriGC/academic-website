# George-Călin Serițan — academic website

Site academic în limba română: profil, cercetare, publicații, educație, CV și contact.
Include 146 de înregistrări bibliografice și pagini dedicate FARCROSS și INTERRFACE.

## Actualizare

Necesită Python 3, fără pachete suplimentare.

```sh
python3 build.py
```

Sursele de conținut se află în `source/` și `build.py`. Site-ul generat este în `docs/`.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /docs → Save.

Design adaptat după https://github.com/EnacheBA/academic-website.
